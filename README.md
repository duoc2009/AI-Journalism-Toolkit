# 📰 AI-Journalism-Toolkit 🚀

### *Empowering Journalists with AI-Driven Efficiency and Editorial Integrity*

---

## 🌟 Overview
**AI-Journalism-Toolkit** is an open-source initiative designed to support digital transformation in modern newsrooms. As a professional journalist at a legal newspaper in Vietnam (**plo.vn**), I am developing this toolkit to help local reporters leverage the power of Large Language Models (LLMs) like **Claude** to navigate the complex information era.

## ✨ Key Features
- 🔍 **Automated Fact-Checking:** Cross-referencing news data with legal documents to ensure accuracy.
- 📝 **Smart Summarization:** Turning long-form reports and legal texts into digestible news snippets for social media and mobile readers.
- 📊 **Infographic Generator:** Assisting in data extraction to create compelling, data-driven visual storytelling.
- 🤖 **News Scraper:** Ethical data gathering from public government and legal portals.

## 🎯 Why This Project Matters
In the age of misinformation, journalists need better tools to maintain public trust. This project aims to:
1. Reduce manual workload for reporters.
2. Ensure higher editorial standards through AI-assisted verification.
3. Help small and local newsrooms in Vietnam access high-tech solutions for free.

## 🛠 Tech Stack
- **AI Model:** Claude (Anthropic) API integration.
- **Language:** Python.
- **Visuals:** Matplotlib / Seaborn for data viz.
